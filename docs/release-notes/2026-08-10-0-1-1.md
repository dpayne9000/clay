Clay 0.1.1 makes local setup and everyday workflow selection clearer.

The new clay configure command manages the model server URL and named model profiles. Before a workflow starts, Clay checks the default model and only the additional profiles that workflow uses. Local llama.cpp GGUF cache paths are matched directly to their Hugging Face repository names, and a real model mismatch now asks before continuing.

Bare clay now starts the improved General Chat workflow by default. Use clay default to see the current selection, clay default set <workflow> to choose another workflow, or clay default reset to follow Clay's managed default again. Recognized older shipped defaults update automatically, while an explicit user choice is preserved.

General Chat now understands Clay's current workflow syntax and operational capabilities, and it can selectively read relevant files from the approved project workspace when answering project questions. The Telegram menu now starts with five useful shipped workflows: General Chat, Coding, Workflow Builder, Code Review, and Web Research.

Daemon launches now check required directory permissions before work becomes unattended. CLI, Telegram, and desktop prompts identify the directory and requested read, write, or command access so it can be approved in advance.

This release also includes workflow, documentation, test coverage, and code-cleanliness fixes from the 0.1.0 follow-up review.
